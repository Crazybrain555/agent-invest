# 06R 查询侧同义映射（受控别名表，qs-2026.07-1）
#
# 收录纪律：
# 1. 只收「法定披露术语的等价称谓或常用俗称」——查询词与目标词零共享词元时
#    才值得建组（共享词元的对，如 回购/股份回购，分词后天然互相命中，禁止入表）。
# 2. 禁止概念联想（配股/送股/转增 是不同概念，不是别名）、跨概念扩展与传递链。
# 3. 每项必须是钉扳分词器（jieba+domain_dict）下的单一词元，加载时校验，
#    违规拒载（fail-closed）。上限 40 组。
# 4. 改动需人工复审，并同步 tokenizer.SEARCH_SYNONYMS_VERSION。
#
# 语法：等价组 `a, b, c`（组内互相扩展）；方向组 `a => b, c`（查 a 时补 b、c，
# 反之不然）。`#` 起为注释。
年报, 年度报告
半年报, 半年度
季报 => 季度
分红, 利润分配, 分派
派息 => 分红, 利润分配, 分派
