# 错杀/低估股研究 Skill（更具体、更可落地版）

> 这套方法的核心不是“找便宜”，而是**找到“被错误定价的价值”**：  
> - **价值**   股票（公司）的实际真实价值 —— 价值可以 来自企业能长期创造现金/复利增长的能力（商业模式 + 护城河 + 管理层），也可以来自公司被并购或者清算时应该被客观计入的价值  
> - **错误定价** 在交易市场上交易的股票市值远低于公司的真实价值   ——比如来自市场把“短期/局部/可修复的问题”外推成“长期/结构性/不可逆的问题”  
>
> 可以考虑大众对某些事件、行业、可能出现偏见或者误解，也存在关注不足产生的信息偏差，研究股票也要深度去了解公司的成长性，周期性，从而了解公司是否存在价值陷阱，虽然存在大众的低关注、低估，但是公司的成长性是否过低，其次公司的管理层、管理风格、公司文化是否健康、具有可持续性；公司的新产品、销售能力等一系列涉及到成长性的要素也要关注，尤其是要关注企业的成长性，独特性，这里面可以透过ROE,利润率,周转率的财务表象了解，但是要深度到产品本身去了解并确认企业的实际护城河，护城河是保证企业能够持续保持优势地位避免过度的恶性竞争。

---

## 1) 核心思想（从“烟蒂”到“合理价格买伟大公司”）

- “烟蒂”可以是**策略分支**（资产/事件驱动），但不应成为默认；  
- 更可持续的主线是 “**伟大公司 + 合理价格 + 长期**”。

---

## 2) 双路线框架：先选“你在做哪一种价值”


### A. 烟蒂/资产折价型（Cigar-butt / Net-net / Liquidation-ish）
适用：公司生意一般甚至很差，但价格明显低于保守资产价值，且**有退出路径**  
- 赚的是：**价值回归 / 资产处置 / 事件驱动**  
- 关键不是护城河，而是：资产能否兑现、负债/或有负债、催化剂可靠性

### B. 错杀复利型
适用：公司是“好生意/至少不差”，护城河真实存在，但市场因为短期问题/误解或者周期等其他原因而市场市值低于估值（考虑了安全边际后的）  
- 你赚的是：**内在价值增长 + 估值修复**  
- 关键是：商业模式是否能持续产现金、护城河是否守得住竞争压力、管理层资本配置能力

> 决策规则（很实用）：  
> - 如果你找不到“资产兑现/事件催化”的逻辑 → 不要把它当烟蒂做  
> - 如果你找不到“护城河证据 + 长期复利路径” → 不要把它当复利错杀做，根据护城河强弱去调整安全边际，成长性越强越明确，可以考虑的安全边际可以越低

---

## 3) 标的初筛方法：

### 3.1 初筛条件
思想是**长期翻 Value Line、重点看新低列表**；看到候选后第一件事先看“是否足够便宜”，不便宜就跳过。

> “候选池生成器”：  
- 52w/3y 新低附近、或相对行业显著跑输  
- 估值低：P/E、P/B、EV/EBIT、P/FCF、FCF yield 位于历史分位很低，或者估值中等，但是在所处行业分位数很低  
- 现金流门槛：过去多年累计 FCF 为正（允许短期为负但必须可解释）  
- 关注度：新闻稀少、卖方覆盖少、管理层不“讲故事”的冷门股（更容易错杀）

### 排除一些行业
 
- 优先选择**你能形成能力圈**的行业，优先选择**优秀公司密度高**的领域，而不是到处找“看起来便宜”的烂资产 ： IT、中概股、AI、医药生物、电力、互联网、制造业、金融业等，排除一些最近三年ROE、净利润低的行业（我还没特别明确，先排除美股30%的盈利少，竞争激烈的行业）

## 4) 深度研究主流程：李路四问 + Munger 反向验证（Inversion）

> 你要的“更深入”，核心是把每一步变成**可证伪/可落表**的检查项。

### Step 1：**Is it cheap?（它真的便宜吗）**
先别急着做 DCF，先做“便宜的结构”：

**对烟蒂型：**
- 计算保守资产价值（现金、应收、存货打折、固定资产打折、减全部负债）
- 明确资产“能否变现”：是否受监管/质押/专用性限制？

**对错杀复利型：**
- 用“正常化”利润/现金流（去掉周期高点/一次性）做估值区间
- 估值不是点，而是区间：`悲观情景 / 中性 / 乐观`
- 重点看“在悲观情景下是否还便宜”（安全边际）

> 关键输出：  
- `Price < Conservative Value` 是否成立  
- 便宜来自哪里：盈利被低估？现金流被误读？短期噪音？复杂会计？

### Step 2：**What’s in the book?（账面里到底有什么）** —— 李路式的“拆资产”
李路在 Timberland 案例里做法很具体：  
- 不只看 P/B，而是**拆 book value 的构成**：现金、固定资产里是否有“高价值/可变现”项（例如地产）:contentReference[oaicite:9]{index=9}  

你可以把它变成模板：
- 现金与等价物：是否被限制使用？  
- 固定资产：是否存在可出售/可回租的优质资产？  
- 无形资产/商誉：如果占比大，要警惕“看似便宜其实是幻觉”  
- 表外：租赁、养老金、诉讼、环保等（这些决定“便宜是否真实”）

### Step 3：**Is it a good business?（它是不是好生意）** —— 护城河要“证据化”
李路在 Timberland 里用一个非常硬的指标验证“好生意”：**ROIC**。:contentReference[oaicite:10]{index=10}  
你要把护城河从“感觉”变成“证据链”：

**护城河证据 1：长期 ROIC > WACC 且稳定**
- 看 5–10 年 ROIC 均值与波动（稳定比高更重要）
- 看 **增量 ROIC / ROIIC**：新投入资本是否也能赚钱（决定能不能复利）

**护城河证据 2：价格能力（pricing power）**
- price/mix 是否长期为正？  
- 行业通胀上行时是否能转嫁？  
- 毛利率在竞争加剧期是否能守住？

**护城河证据 3：份额稳定（或可解释的波动）**
- 行业下行时公司是否只是跟随行业？还是跌得更惨（丢份额）？

> 关键输出：  
- 写清楚“护城河来自哪里”：切换成本？渠道？规模？品牌？监管认证？后市场？  
- 同时写清楚“最容易被打穿的点是什么”。

### Step 4：**Who is running it?（谁在经营它）** —— 管理层与行业环境缺一不可
李路在北大 Q&A 里强调两点，非常适合作为“管理层模块”的硬要求：  
- 你要理解公司，必须理解**管理层**与**行业基本驱动力**；很多行业结果更多由竞争环境决定，不完全由某个“天才管理者”决定。:contentReference[oaicite:11]{index=11}  
- 研究人员要能描述**10 年后的最坏情形**；否则不能说你理解这家公司。:contentReference[oaicite:12]{index=12}  

管理层评价落地成三张表：

**(1) 资本配置成绩单（Capital Allocation Report Card）**
- 回购是否在便宜时做？还是高估值追回购  
- 并购：是增强护城河/能力圈，还是“并购成瘾”稀释回报  
- 杠杆：是否为了 EPS 好看去加杠杆，牺牲长期安全性

**(2) 激励与文化**
- KPI 是否鼓励短期冲量（牺牲毛利/现金流）？  
- 是否长期坚持“一致的策略”（策略频繁摇摆通常意味着没有护城河）

**(3) 透明度与诚实**
- 对坏消息是否提前披露、是否能量化解释  
- 是否能给出可验证的目标与路径

### Step 5：**Why is it cheap?（为什么会被低估）** —— 错杀研究的灵魂
把“便宜原因”分成两类，并写出证据与验证指标：

**可逆型（更像错杀）**
- 周期底部（需求下滑但行业终会回归均值）
- 一次性事件（诉讼/召回/短期执行失误）
- 会计噪音（摊销/折旧周期/一次性减值影响 GAAP）
- 市场误分类（把它当成夕阳行业，但公司在细分里有结构性优势）

**不可逆型（更像价值陷阱）**
- 定价权丢失 → 只能靠促销  
- 技术替代正在发生（不是“可能”，而是已经在报表/份额里体现）  
- 竞争格局恶化（平台捆绑/白牌化/价格战无解）

> 输出必须包含：  
- “市场叙事”是什么  
- 你反驳它的**关键证据**是什么  
- 未来 2–6 个季度用哪些数据就能证明你对/错（硬指标）

### Step 6：**What did I miss?（我遗漏了什么）** —— Munger 的反向思维 + 避免大错
Munger 强调“避免大错”与“反向思考（inversion）”：先列出会导致失败的路径，然后逐条排除。:contentReference[oaicite:13]{index=13}  

把它制度化成 **Pre-mortem（投资前验尸）**：
- 假设这笔投资三年后失败：最可能的 3 个原因是什么？
- 哪个原因一旦发生会导致“永久性损失”（不是波动）？
- 你现在能否用数据监控它的早期信号？

并用李路的“10年最坏情景”作为最终门槛：  
> 你必须能写出“10年后最坏会怎样”，否则说明你不在能力圈内。:contentReference[oaicite:14]{index=14}

## 5) 护城河与竞争压力：从“定性”走向“可检验的证据”

> 你提的“护城河深不深、竞争压力大不大”，要靠“证据清单”而不是口号。

### 5.1 护城河证据清单（按强度排序）
1. **强粘性 / 切换成本**：迁移成本、认证周期、流程嵌入、数据锁定  
2. **后市场锁定**：存量设备/装机量带来的服务与耗材现金流  
3. **规模优势**：单位成本、供应链、渠道覆盖、履约能力  
4. **品牌溢价**：能提价且销量不崩（注意：很多消费品品牌并不强）  
5. **监管/许可壁垒**：认证、资质、合规成本  
6. **网络效应/生态**：用户越多越强（要验证“强者恒强”是否真的发生）

### 5.2 竞争压力热力图（你可以直接表格化）
- 价格战风险：高/中/低（毛利趋势 + 同业策略）  
- 替代风险：高/中/低（技术路线变化是否进入财务体现）  
- 客户/渠道议价权：高/中/低（集中度、合同期限、可替代性）  
- 份额稳定性：强/中/弱（行业下行期的相对表现）

> 关键：竞争格局是“能解释财报的”。  
如果你说竞争激烈，但毛利/份额长期稳定，那可能恰恰说明护城河存在；  
如果你说护城河强，但毛利持续被挤压、份额下滑，那就是自欺欺人。

## 6) 收入稳定性与份额：把“行业下滑”与“公司丢份额”拆开

> 你之前强调“必须分项研究，看行业 vs 公司”，这是判断错杀/陷阱的关键。

### 6.1 收入拆解树（每季度都能复用）
把收入变化拆成：
- 行业总需求（TAM）
- 份额（share）
- 价格/组合（price/mix）
- 供给与执行（交付、缺货、良率、渠道库存）
- 主动策略（砍 SKU、退出低毛利等）

### 6.2 当公司不披露份额时：用 proxy 推断
- 行业销量/订单/产量（整车/物流/上游等）
- 同链条公司（上下游财报）
- 多年份去基数（2–3年复合），排除偶发高基数

> 判定规则：  
- 公司下滑≈行业下滑 → 更可能是周期  
- 公司显著更差 → 需要找“份额丢失/客户替换”的证据

## 7) 催化剂与时间：烟蒂靠“催化”，复利靠“时间”

- 烟蒂型：你必须写清楚“怎么退出”（资产处置、回购/私有化、重组、清算、事件）  
- 错杀复利型：你必须写清楚“内在价值如何增长”，并让时间成为朋友  
  - 这背后的逻辑就是：好生意在时间中更占便宜，平庸生意在时间中更吃亏:contentReference[oaicite:15]{index=15}

## 8) 研究输出（必须可复用）：一页 Memo + Dashboard + 证伪条件

### 8.1 One-page Memo（固定格式）
- 市场最悲观叙事（1段）
- 你的反叙事：为什么可能被过度外推（1段）
- 商业模式：钱怎么赚、稳定器是什么
- 护城河：证据链（ROIC/毛利/份额/切换成本等）
- 竞争压力：主要对手与竞争方式，价格战/替代风险判断
- 管理层：资本配置成绩单 + 激励
- 估值：悲观/中性/乐观三情景的内在价值区间
- 催化剂：2–6季度内能验证的硬指标
- 证伪条件：发生什么就承认自己错

### 8.2 Dashboard（监控面板）
- 用 6–12 个指标覆盖：收入拆解、毛利/费用率、现金流、杠杆、份额 proxy、关键运营指标  
- 每个指标写一句：**上升/下降分别意味着什么**

## 9) 示例：用李路的 Timberland 案例把“四问”跑一遍（你要的“具体”）

> 这个例子之所以适合做 skill，是因为它把“便宜—拆账—好生意—为何便宜”串成闭环。

1) **Is it cheap?**  
   - 他先看估值：低倍数（P/E 很低），不便宜就不看:contentReference[oaicite:16]{index=16}  

2) **What’s in the book?**  
   - 拆 book：现金、固定资产等构成；并进一步发现固定资产里有可变现价值（例如商业地产），并结合季节性（旺季现金流）判断“账面会更厚”:contentReference[oaicite:17]{index=17}  

3) **Is it a good business?**  
   - 用 ROIC 验证“好生意”，并用利润率/投入资本推导回报水平（不是只看增长故事）:contentReference[oaicite:18]{index=18}  

4) **Why is it cheap?**  
   - 把“市场为什么错”写清楚（宏观/区域恐慌导致的误伤、对收入结构误判等），并证明“即使砍掉最悲观那块，仍然便宜”。  
   - 这一步对应你要找的“被误解→错杀”。（同类逻辑你可以迁移到任何行业的“误分类”里）:contentReference[oaicite:19]{index=19}  

5) **What did I miss?**  
   - 最终必须能写出“10年最坏情景”，否则不算理解（李路在 Q&A 里把这当作研究人员硬标准）。:contentReference[oaicite:20]{index=20}

## 10) 你要的“更深的最终一句话”（作为 skill 的验收标准）

> **如果你不能把护城河写成证据链、把竞争压力写成可验证的财务/运营表现、把“为何便宜”写成可证伪的情景与指标，那么这就不是 Munger/李路意义上的价值投资，只是“看起来很便宜”的叙事。**:contentReference[oaicite:21]{index=21}
